# Configuration 
The configuration file will look something like this:
```
{
  "ArmourDurability": false,
  "Coords": false,
  "FpsDisplay": false,
  "Keystrokes": false,
  "FpsX": 100,
  "FpsY": 100
}
```
Modules listed in the mod menu in game are the modules. <br>
FpsDisplayTypeX can be either "centre" or "coordinate" with "centre" obviously being centred and "coordinate" enabling the use of FpsX and FpsY.
This is the same for most other module display types.
